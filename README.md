## Ответы на вопросы
1. Поле класса привязанно к конкретному объекту или классу, а переменная функциии существует только во время ее выполнения.
2. Конструктор - это специальный метод, который вызывается при создании объекта. Он нужен для инициализации объекта.
3. @override нужен для указания намеренного переопределения метода родительского класса. Если его убрать программа будет работать точно так же, но не будет защиты от опечаток.
4. Статическое поле static int _counter пренадлежит классу, а обычное поле - объекту класса. В программе существует одна копия такого поля.
5. _ делает идентификатор приватным для файла, а не для класса.
